## 一、项目概述

Vox Deorum 和 CivBench 是 2025 年围绕《文明 V》的两篇连续论文，代表了目前**最大规模**的 LLM 文明游戏实验。

### 为什么选文明 V（而非 VI）？

| 原因 | 说明 |
|------|------|
| **Vox Populi mod** | 社区增强 AI，比原版算法 AI 强得多——是更强的基线 |
| **开放 modding API** | 比文明 VI 更容易进行游戏状态读写 |
| **维护良好的代码库** | 多年社区开发积累 |
| **成本可控** | 需求低于文明 VI，适合**大规模**实验 |

## 二、Vox Deorum：混合 LLM+X 架构

### 2.1 核心思想：LLM 不需要做一切

```
┌─────────────────────────────────────────┐
│           LLM Strategist                 │
│  高层战略推理：选择胜利条件、科技路径     │
│  评估威胁与机会、设定外交姿态             │
├─────────────────────────────────────────┤
│         Algorithmic Executor (X)         │
│  战术执行：单位移动/战斗、市民分配        │
│  建造队列管理、具体外交操作               │
└─────────────────────────────────────────┘
```

"X" = Vox Populi 社区 mod 的增强 AI（VPAI）。

### 2.2 LLM 策略师的输入/输出

**输入（每回合）**：自然语言摘要——分数、城市、单位、科技、外交 + 可用战略选项

**输出**：胜利条件选择 + 优先科技路径 + 对每个对手的外交姿态 + 战略优先级

**关键设计**：LLM **不**直接操作单位或城市——避免了 Civ6-MCP 中发现的执行鸿沟。

### 2.3 实验规模

| 维度 | 数值 |
|------|------|
| **总对局数** | **2,327 场**（远超所有其他项目） |
| **LLM 模型** | GPT-OSS-120B, GLM-4.6 |
| **基线** | Vox Populi AI（VPAI，算法 AI） |
| **每局成本** | 约 **$0.86** |
| **每回合延迟** | 约 **15 秒** |
| **存活率** | 约 **97%** |

### 2.4 核心结果

#### 统计持平的竞争力

| 指标 | LLM 策略师 vs VPAI |
|------|-------------------|
| 胜率 | **统计上无显著差异** |
| 得分比 | **统计上无显著差异** |

**首个 LLM Agent 在文明游戏中与算法 AI 统计持平的大规模实验。**

#### 截然不同的策略风格

| 模型 | 策略特征 | 策略切换频率（/100 回合） |
|------|---------|------------------------|
| **GPT-OSS-120B** | **+31.5%** 偏好统治胜利，激进扩张 | ~14 |
| **GLM-4.6** | 胜利条件更均衡，偏科技/文化 | ~34 |
| **VPAI（算法）** | 高度机会主义 | ~52 |

#### 战略"固执"（Strategic Stubbornness）

LLM 策略师比算法 AI **更少切换战略**：
- 算法 AI 每 100 回合切换 ~52 次 → 高度机会主义
- LLM 每 100 回合仅切换 14–34 次 → 更有战略一致性

**双面性**：一致性是好战略的要素，但当条件变化时拒绝调整可能导致 Civ6-MCP 中 Claude 的隧道视野。

#### 可行性

| 指标 | 数值 | 评价 |
|------|------|------|
| 成本 | **$0.86/局** | ✅ 适合大规模运行 |
| 延迟 | 15s/回合 | ✅ 回合制可接受 |
| 存活率 | 97% | ✅ 几乎不会崩溃 |
| 竞争力 | 统计持平 | ✅ **达到实用门槛** |

## 三、CivBench (Civ V)：基于进度的评估

### 3.1 问题：终局胜负过于稀疏

- 一场游戏 300+ 回合 → 仅一个二进制信号
- 无法区分"从头被碾压"和"领先 200 回合最后被翻盘"
- Elo 竞技场需要海量对局

### 3.2 解决方案：回合级胜利概率信号

```
回合 50:  48% (均势)
回合 100: 35% (开始落后)
回合 150: 22% (明显劣势)
回合 200: 61% (调整奏效)
回合 250: 85% (确立优势)
回合 300: 92% → 最终胜利
```

**优势**：密集信号（每回合可评估）、更细粒度（区分不同失败/胜利质量）、策略画像（看出在哪阶段擅长/薄弱）、样本效率（不需要海量终局数据）

### 3.3 效度验证

| 效度类型 | 方法 | 结果 |
|----------|------|------|
| **预测效度** | 概率是否准确预测最终胜负？ | ✅ 校准良好 |
| **建构效度** | 概率是否符合理论（经济领先→高胜率）？ | ✅ 符合 |
| **收敛效度** | 不同评估方法是否收敛一致？ | ✅ 一致 |

### 3.4 多模型基准

7 个 LLM × 307 场多人对战：Claude Sonnet-4.5, Kimi-K2.5, MiniMax-M2.5, Qwen-3.5, GLM-4.7, DeepSeek-V3.2 等。

### 3.5 策略画像洞察

基于进度的评估揭示了仅靠终局胜负看不到的模式：
- 某些模型**早期**强势（快速扩张），**中后期**衰落
- 某些模型在**落后时**展现更强的韧性
- 不同模型的胜利条件偏好差异明显

## 五、对六朝项目的启示

| 启示 | 具体建议 |
|------|---------|
| **混合架构最实用** | LLM 战略层 + 规则/算法战术层——降低 LLM 负担，提高可靠性 |
| **大样本量至关重要** | 12 场的经验教训和 2,327 场的统计结论质量完全不同 |
| **进度评估 > 胜负评估** | 回合级/阶段级进度指标比"谁赢了"提供更丰富信息 |
| **策略固执的双面性** | LLM 的坚持是双刃剑——需要机制在关键条件变化时强制重新评估 |
| **$0.86/局的成本参考** | 文明类游戏的 LLM 策略师可以在合理成本内运行 |
| **多模型对比** | 不同 LLM 的策略风格可能截然不同——需要横向对比才能发现 |
| **回合制 = 低延迟要求** | 15s/回合延迟证明：策略游戏中 LLM 推理时间不是瓶颈 |
