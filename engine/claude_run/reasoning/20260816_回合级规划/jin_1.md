# 东晋1（桓温）决策日志 · 回合级规划测试

## 初始战略（读规则后）

核心矛盾是「三家共养司马家 vs 各抢个人 VP」——司马家终局 VP 的分配系数由个人威望/功绩排名决定（第一名+3、第二名+2、第三名+1），且威望/功绩必须≥3 才能拿到系数。所以开局尽早冲到威望≥3（对非友方地点进军/转化各给1威望），同时靠「存档候选策略牌」和「手牌行动打策略牌」攒功绩，确保自己两条轨都不垫底、最好争到第一名系数。资源争夺：三家共享一副东晋牌库、先到先得——优先抢高价值候选策略牌（尤其能进军的，北伐标记是扩大相邻范围、抢司马家区控奖励的关键），把低质牌存档清出。北伐方向借司马家江南/荆襄/淮南为跳板，向北打中原（6/8）和关中。

**定位：激进抢威望 + 精修牌库 + 盯紧中原高VP区。**

## 第 1 回合规划

**核心：抢北伐标记打通中原、起威望、建军事引擎。**

军力：起始1→北伐+2=3→进军谯-3=0→征募+1=1→占据谯-1=0。

1. 牌组行动「北伐」（+2军力+北伐标记）：北伐标记本回合生效，把司马家寿春/广陵视为己方相邻，才能从襄阳/南郡直接打进中原的谯/彭城，否则只能打荆襄宛城；北伐是共享牌库先到先得，抢到即断对家。
2. 手牌行动「高卧东山」（费0）：检索2张策略入手，自己存档触发桓温被动+2vp。
3. 进军谯（中原，中立非友方）+1vp+1威望。
4. 征募补1军力。
5. 占据谯（use_sima=false）用自己的部队，推进中原并翻自己部队储备VP。

### 重规划（谯被东晋2抢走）

谯已被东晋2(王导)占据，改打宛城。军力：北伐后3→进军宛城-3=0→征募弃鸠摩罗什+1=1→占据宛城-1=0。

选宛城(荆襄)而非雍丘/彭城：宛城与我的襄阳直接相连，是连成一片的稳妥扩张，同时是下回合进军洛阳/雍丘（中原6/8VP区）的门户，并向荆襄4/6控制迈进；雍丘虽在中原但与现地盘不相连、还紧贴邺城（北方南下方向），是孤悬前哨风险高。进军中立宛城仍得+1威望+1vp。

【重规划】进军宛城→征募弃鸠摩罗什→占据宛城→end_turn
