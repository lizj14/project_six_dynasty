# 北方（north）决策日志

## 初始战略（读规则后）

立足北方天然优势（部队多、军力高、先动、独享牌库），前期快速在河北/幽燕/塞外铺开占据，抢高 VP 的【中原】(6/8) 和【河北】(2/3) 区控，同时卡住东晋北伐的咽喉要道；牌库优先补军力和进军/占据类策略牌，形成每回合稳定产出军力的滚雪球引擎，压制东晋三家的扩张与文化传播，最终以区控 VP + 部队 VP 取胜。

## 初设

【思考】先看英雄：两个英雄主动都是「弃1手牌摸1 + 送一个额外行动」，差别只在送手牌行动（苻坚）还是牌组行动（慕容儁），属次要差异；真正拉开差距的是登场转化。慕容儁转蓟城/龙城/中山 = 幽燕2+河北1，偏安一隅扩张慢 VP 低。苻坚转长安/弘农/安定/平阳 = 关中2（=关中部分控制，2VP/回合）+ 中原1 + 山西1，且长安是枢纽、弘农是进中原（全图最高 6/8 VP）的桥头堡，位置更中心更进攻。故选苻坚。

暗置牌：暗置策略牌进牌库顶（无即时效果），暗置幕僚牌进幕僚区立刻结算登场。10 张里只有姚苌有强登场「转化2个相邻中立」+ 每回合主动 +1军力。配合苻坚的 4 地，姚苌登场可再吃下天水（凑满关中 3/3 = 完全控制 VP 2→3）+ 洛阳（中原枢纽），开局即 6 地 + 关中完全控制。费用仅 2，弃掉的牌正好是费1策略「尊奉江东」（送东晋牌，反作用）和「幽州突骑」（需控幽燕，与苻坚位置不搭）这两张最没用的。邓羌虽强但无登场且费3，开局价值不如姚苌。

放弃：慕容儁（位置偏、VP 低）；邓羌/慕容恪暗置（无即时登场且费3）；策略牌暗置（无即时效果）。
