## E001 — 2026-08-01

**配置**：
- 模型：deepseek-v4-pro
- 温度：0.3
- max_tokens：4096
- 规则书：完整 rulebook.md
- 卡表：完整 card_design.csv（150张）
- 地图：完整 map_adjacency.yaml
- 游戏状态：真实引擎跑至 T3 行动阶段开始

**游戏场景**：
- 回合3，行动顺序：north → jin_3 → jin_1 → jin_2
- 主角 jin_3：VP=15，军力=1，手牌6张，幕僚区=尹纬
- 朝堂区：土断、士卒、流民、征辟人才、北伐、兴修水利、加官进爵、宫廷、士卒、清谈

**LLM 输出摘要**：
- 手牌行动 → 刘琨（转化太原+平阳，存档）
- 牌组行动 → 土断（僭越压制对手，获3军力）
- 快速行动 → 摸牌 + 征募

**问题记录**：
1. LLM 自称"王导"但实际英雄需核实
2. 资源链未完整验证（刘琨费用2需2张手牌支付，土断朝堂行动成本未计算）
3. 僭越条件判断可能不准确

**结论**：LLM 能产出有质量的战略分析，方向可行。后续需调 prompt 提升精确度。

## E002 — 2026-08-01

**配置**：
- 模型：deepseek-v4-pro
- 温度：0.3
- max_tokens：8192（E001 被 4096 截断后调大）
- seed：43（默认从42改为43）
- 其他同 E001

**游戏场景**：
- 回合3，行动顺序：north → jin_2 → jin_3 → jin_1
- 主角 jin_2：手牌仅3张（兰亭集序3费、胡笳羌笛3费、焉能有功），幕僚区=空，VP领先
- 朝堂区(晋)：8张，含北伐等
- 江南区域：京口、浔阳为空地，其他由司马家控制

**LLM 输出摘要**：
- 手牌行动 → **跳过**（手牌均为高费事件牌无法支付，强行弃牌将枯竭）
- 牌组行动 → 北伐（获2军力+北伐标记，用于扩大相邻范围）
- 快速行动 → 征募(弃焉能有功) → 占据京口 → 占据浔阳(靠北伐标记) → 加固京口
- 战略方向：完全控制江南区域，牺牲短期手牌换地盘长远优势

**E001 vs E002 对比**：
| 维度 | E001 (jin_3) | E002 (jin_2) |
|------|-------------|-------------|
| 手牌数 | 6 | 3 |
| 幕僚 | 尹纬(在场) | 无 |
| 手牌行动 | 刘琨(转化太原平阳) | 跳过 |
| 战略重点 | 北伐扩张 | 稳固江南 |
| 行动复杂度 | 高 | 低（资源紧张） |

**问题记录**：
1. 手牌仅3张且均为高费，LLM 正确判断跳过手牌行动——展现了资源约束下的理性决策
2. 北伐标记 + 双占据 + 加固的资源链计算基本正确
3. max_tokens 需 ≥ 8192，4096 会导致截断

**结论**：两个不同种子产生差异很大的局面，LLM 均能据此调整策略。E002 展现了「资源紧张时选择跳过」的理性行为。
