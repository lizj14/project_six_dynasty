## 游戏概述
- 4人游戏：1个北方玩家 + 3个东晋玩家
- 司马家是非玩家角色，是东晋玩家的友方
- 最多10回合，VP最高者获胜
- 核心机制：牌组构筑+区域控制。北方玩家独立DBG，东晋玩家共享国家牌库
- 每回合每位玩家可执行：1个手牌行动 + 1个牌组行动 + 任意次快速行动

## 地图概念
- 点线式地图，12个区域，每个区域包含若干地点
- 区域控制：地点数 > 阈值(总数/2) → 获得控制标记
- 相邻：与己方占据地点直接相连的地点
- 友方地点：北方=自己，东晋=所有东晋+司马家
- 实线=简单地形，虚线=困难地形(进军费用+1)
- 孤立地点：所有相邻地点都不是友方 → 进军费用-1
- 北伐标记：东晋玩家获取后，本回合相邻计算扩大到所有友方地点

## 资源系统
- 卡牌：每回合摸2张，手牌无上限(行动结束时保留8张)
- 军力：每回合行动结束时基于部队储备区获得，行动结束时清0
- 快速行动-征募：弃1手牌获1军力
- 快速行动-摸牌：2军力摸1牌(每回合1次)

## 回合流程
一个回合 = 准备阶段 → 行动阶段 → 结算阶段

**准备阶段**：
1. 投君主骰（司马家每3军力投1个，最多5个）
2. 放置东晋行动顺位
3. 重置公共行动牌区
4. 结算东晋区域控制奖励

**行动阶段**（按顺序，北方先，然后东晋按顺位）：
轮到每位玩家时：
1. 结算区控奖励（自己控制的区域）
2. 从主版图牌库摸2张牌
3. 以任意顺序执行：1个手牌行动 + 1个牌组行动 + 任意次快速行动

玩家确认结束后，军力清0，手牌超过8张需弃至8张。

**结算阶段**：
1. 检查游戏结束条件
2. 未被选的候选策略牌按资源选项结算
3. 摸新候选策略牌（各10张）
4. 玩家基于部队储备区获得军力
5. 君主年龄结算

## 行动效果

### 手牌行动
从手牌中选1张支付费用后结算：
- 幕僚牌 → 放入幕僚区（东晋上限3张，北方上限4张）
- 事件牌 → 结算后弃入主版图弃牌区
- 策略牌 → 放入所在国家牌库顶（之后回合会出现在朝堂区）

### 牌组行动
从朝堂区候选策略牌中选1张，支付行动费用后结算效果，放入出牌区。

### 快速行动（任意次数）：
| 行动 | 费用 | 效果 |
|------|------|------|
| 占据 | 1军力 | 在相邻空地点放1个部队 |
| 进军 | 3军力起 | 移除相邻非友方地点上的部队，获1VP(+东晋获1威望) |
| 摸牌 | 2军力 | 摸1张牌(每回合1次) |
| 征募 | 弃1手牌 | 获1军力 |
| 加固 | 1军力 | 友方地点放加固标记(每回合1次) |

进军费用调整：目标加固+1，困难地形+1，孤立地点-1，最低1军力。

### 东晋特有
- 提高顺位：前进1格(不影响本回合)
- 占据时可选放司马家部队(消耗司马家1军力)
- 东晋每次进军非友方获1威望
- 东晋每次存档或打出策略牌获1功绩

### 转化行动
移除一个被占据地点上的部队，放自己的部队。对非友方转化获1威望+2VP。

### 传播文化
选儒学/玄学/佛学之一，在己方控制的区域或与该文化已存在区域相邻的区域放文化标记。获得VP(该区域及相邻区域该文化标记数，上限5)，提升贡献度1级。

### 征发
选朝堂区一张牌，获得其资源效果(军力/VP)，不触发行动效果，放入出牌区。

## 僭越机制
部分牌有【僭越】标记，效果分两段：
- 基本效果：任何满足条件的玩家可结算
- 僭越效果：仅当东晋玩家威望高于其他东晋玩家+司马家时才能结算

## 关键数值
- 进军官费：3军力(最低1)
- 幕僚上限：东晋3，北方4
- 手牌保留上限：8张
- 文化贡献度轨道：0-10
- 功绩/威望/军力轨道：0-9
- 第10回合强制结束
