# 森森不息 (Forest Shuffle) 规则摘要

## 基本信息

| 项目 | 详情 |

| 英文名 | Forest Shuffle |

| 出版商 | Lookout Games |

## 核心机制

卡牌成套收集 (Set Collection)、手牌管理 (Hand Management)、多重卡牌用途 (Multi-Use Cards)、按回合推进的随机结束计时器。

## 卡牌类型（3种）

### 1. 树木牌 (Tree Cards)
- 左上角棕色矩形显示费用（0-2）
- 上下左右各一个插槽
- 打出树木时，从牌库顶翻1张加入空地
- 任何手牌可面朝下作为「树苗」打出（不属于任何树种）

### 2. 森林居民牌 (Forest Dweller Cards)
- 卡牌分为上下或左右两半，各是一种生物
- **只能选择其中一半打出**
- 放置在树木的空槽上
- 另一半被隐藏，不可见部分的效果不触发

### 3. 冬季牌 (Winter Cards)
- 共3张
- 第1张在牌库剩余约1/3时出现
- 第3张被抽出时，游戏立即结束（不完成当前回合）

## 回合流程

每回合二选一：

1. **抽牌**：从空地和/或牌库顶共抽2张（手牌上限10张）
2. **打牌**：支付费用（弃手牌到空地），放置卡牌并触发效果

**奖励行动**：支付费用时若所用弃牌的花色符号全部匹配打出卡牌的符号，触发额外奖励。

空地≥10张时，回合结束时清空。

## 游戏结束

第3张冬季牌被抽出 → 游戏立即结束。

计分 = 森林中所有可见卡牌的VP总和 + 洞穴中每张隐藏的牌1VP。

## 主要策略流派

| 流派 | 核心思路 |
|------|---------|
| 狼鹿流 | 鹿给狼提供5VP/只，指数增长 |
| 蝴蝶流 | 零费蝴蝶，配合鼹鼠/刺猬铺场 |
| 灌木铺场流 | 低费灌木+蘑菇，形成过牌永动机 |
| 蝙蝠流 | 凑3种蝙蝠，每只固定5VP |
| 八树流 | 橡树+野草莓，8种树种各1棵=10VP |
