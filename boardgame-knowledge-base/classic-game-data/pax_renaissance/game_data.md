## 四种胜利条件

1. **帝国胜利 (Imperial Victory)**：控制最多的王国（至少比其他玩家多2个）
2. **文艺复兴胜利 (Renaissance Victory)**：最多的共和国+最高的法律威望
3. **全球化胜利 (Globalization Victory)**：最多的发现威望+最多的特许权
4. **神圣胜利 (Holy Victory)**：主导宗教+最多的宗教威望

## 8种可用行动

1. **购买卡牌** (Buy Card)
2. **出售卡牌** (Sell Card)
3. **打出卡牌** (Play Card)
4. **东西方操作** (East/West Operations) - 激活桌上一侧的所有操作图标
5. **东西方贸易集市** (East/West Trade Fair)
6. **宣布胜利** (Declare Victory)

## 9种操作 (Operations)

当选择"操作"行动时，激活卡牌上的操作图标：

### 宗教类
- **宗教裁判 (Inquisitor)**：放置/移动主教，沉默卡牌

### 政治类
- **斩首 (Behead)**：**杀死同一帝国位置的对方的桌面卡牌并弃掉**
- **征税 (Tax)**：从帝国收取资金
- **镇压 (Repress)**：将棋子移至"被镇压"状态，获得金币
- **投票 (Vote)**：改变区域的政体类型（王国↔共和国）

### 经济类
- **商业 (Commerce)**：从市场获得1金币

### 军事类
- **海盗 (Corsair)**：移动海盗棋子
- **围攻 (Siege)**：移除区域内的骑士/车/海盗
- **战役 (Campaign)**：征服邻接帝国
